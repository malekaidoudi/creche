# 🚀 DÉPLOYER FRONTEND SUR VERCEL + DOMAINE PERSONNALISÉ

## 📋 PRÉREQUIS

- ✅ Compte GitHub avec le repo `creche-site`
- ✅ Domaine `mima-elghalia.com` acheté
- ⏳ Compte Vercel (gratuit)

---

## 🎯 ÉTAPE 1 : CRÉER COMPTE VERCEL (2 min)

1. **Aller sur** : https://vercel.com/signup
2. **Cliquer** : "Continue with GitHub"
3. **Autoriser** Vercel à accéder à GitHub
4. **Confirmer** l'email

---

## 📦 ÉTAPE 2 : IMPORTER LE PROJET (3 min)

1. **Dashboard Vercel** : https://vercel.com/dashboard
2. **Cliquer** : "Add New..." → "Project"
3. **Sélectionner** : `malekaidoudi/creche` (votre repo)
4. **Cliquer** : "Import"

### **Configuration du projet** :

```
Framework Preset: Vite
Root Directory: frontend
Build Command: npm run build
Output Directory: dist
Install Command: npm install
```

### **Variables d'environnement** :

Ajouter cette variable :
```
VITE_API_URL = https://creche-backend.onrender.com
```

5. **Cliquer** : "Deploy"

⏳ **Attendre 2-3 minutes** (premier déploiement)

---

## ✅ ÉTAPE 3 : VÉRIFIER LE DÉPLOIEMENT (1 min)

Après le déploiement, Vercel vous donne une URL :
```
https://creche-xxxxx.vercel.app
```

1. **Cliquer** sur l'URL
2. **Vérifier** que le site fonctionne
3. **Tester** une inscription

---

## 🌐 ÉTAPE 4 : CONFIGURER LE DOMAINE PERSONNALISÉ (5 min)

### **Sur Vercel** :

1. **Projet** → **Settings** → **Domains**
2. **Ajouter** : `mima-elghalia.com`
3. **Cliquer** : "Add"

Vercel va vous donner des enregistrements DNS à ajouter.

### **Enregistrements DNS à ajouter** :

Vercel recommande généralement :

#### **Option A : Enregistrement A (Recommandé)**
```
Type: A
Nom: @
Valeur: 76.76.21.21
TTL: 3600
```

#### **Option B : Enregistrement CNAME**
```
Type: CNAME
Nom: www
Valeur: cname.vercel-dns.com
TTL: 3600
```

---

## 🌐 ÉTAPE 5 : AJOUTER LES DNS CHEZ VOTRE HÉBERGEUR (5 min)

### **Si GoDaddy** :

1. **Aller sur** : https://dcc.godaddy.com/manage/dns
2. **Sélectionner** : `mima-elghalia.com`
3. **DNS** → **Manage**
4. **Ajouter** les enregistrements fournis par Vercel
5. **Sauvegarder**

### **Si Namecheap** :

1. **Aller sur** : https://ap.www.namecheap.com/domains/list
2. **Manage** → `mima-elghalia.com`
3. **Advanced DNS**
4. **Ajouter** les enregistrements
5. **Sauvegarder**

### **Si OVH** :

1. **Aller sur** : https://www.ovh.com/manager/web/
2. **Sélectionner** : `mima-elghalia.com`
3. **Zone DNS**
4. **Ajouter** les enregistrements
5. **Valider**

### **Si Cloudflare** :

1. **Aller sur** : https://dash.cloudflare.com
2. **Sélectionner** : `mima-elghalia.com`
3. **DNS**
4. **Ajouter** les enregistrements
5. **Save**

---

## ⏳ ÉTAPE 6 : ATTENDRE LA PROPAGATION (5-30 min)

Les enregistrements DNS prennent **5 à 30 minutes** pour se propager.

### **Vérifier la propagation** :
1. Aller sur : https://dnschecker.org
2. Entrer : `mima-elghalia.com`
3. Vérifier que les enregistrements apparaissent

---

## ✅ ÉTAPE 7 : VÉRIFIER SUR VERCEL (1 min)

1. **Retourner sur Vercel** → Settings → Domains
2. **Attendre** que le statut passe à "Valid Configuration"
3. **Certificat SSL** : Automatiquement généré par Vercel

---

## 🎉 ÉTAPE 8 : TESTER LE SITE (2 min)

1. **Aller sur** : https://mima-elghalia.com
2. **Vérifier** :
   - ✅ Site accessible
   - ✅ HTTPS activé (cadenas vert)
   - ✅ Formulaire d'inscription fonctionne
   - ✅ API backend accessible

## 🔄 DÉPLOIEMENTS AUTOMATIQUES

### **Comment ça marche** :

1. Vous faites un changement dans le code
2. Vous commitez et pushez sur GitHub
3. Vercel détecte le push
4. Vercel build et déploie automatiquement
5. Le site est mis à jour en 2-3 minutes

### **Commandes** :
```bash
cd /Volumes/Works/Windsurf/creche-site
git add -A
git commit -m "Mise à jour frontend"
git push origin main
```

⏳ **Attendre 2-3 min** → Site mis à jour automatiquement !

## 🆘 DÉPANNAGE

### **Erreur : "Domain not configured"**

**Cause** : DNS pas encore propagés

**Solution** : Attendre 15-30 minutes

### **Erreur : "Build failed"**

**Cause** : Erreur dans le code ou configuration

**Solution** :
1. Vérifier les logs Vercel
2. Vérifier que `Root Directory = frontend`
3. Vérifier que `Build Command = npm run build`

### **Site accessible mais API ne fonctionne pas**

**Cause** : Variable `VITE_API_URL` manquante

**Solution** :
1. Vercel → Settings → Environment Variables
2. Ajouter : `VITE_API_URL = https://creche-backend.onrender.com`
3. Redéployer
