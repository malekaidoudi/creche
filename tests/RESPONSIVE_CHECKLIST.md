## 🎨 Critères Généraux

### Navigation
- [ ] Menu hamburger fonctionnel sur mobile
- [ ] Sidebar collapsible sur tablet
- [ ] Breadcrumbs visibles sur desktop
- [ ] Retour arrière accessible sur mobile
- [ ] Navigation bottom bar sur mobile (optionnel)

### Typographie
- [ ] Taille minimale 14px sur mobile
- [ ] Taille minimale 16px sur desktop
- [ ] Titres proportionnels (responsive)
- [ ] Espacement lignes approprié
- [ ] Contraste suffisant (WCAG AA)

### Boutons & Interactions
- [ ] Taille minimale 44x44px sur mobile
- [ ] Espacement suffisant entre boutons
- [ ] États hover/active visibles

- [ ] Pas de double-tap nécessaire

- [ ] Images responsive (srcset/picture)
- [ ] Lazy loading activé
- [ ] Pas de débordement

- [ ] Fallback si erreur

- [ ] Inputs larges sur mobile (100%)
- [ ] Labels visibles
- [ ] Validation en temps réel
- [ ] Messages d'erreur clairs
- [ ] Autocomplete approprié
- [ ] Keyboard navigation fonctionnelle

### Performance
- [ ] Pas de scroll horizontal
- [ ] Pas de débordement de contenu
- [ ] Animations fluides (60fps)
- [ ] Temps de chargement < 3s
- [ ] Images optimisées

### Accessibilité
- [ ] Contraste couleurs suffisant
