# ⚙️ CONFIGURATION EXACTE VERCEL

## 🎯 SETTINGS → GENERAL

### **Build & Development Settings** :

```
Framework Preset: Vite

Root Directory: frontend

Build Command: npm run build

Output Directory: dist

Install Command: npm install

Node.js Version: 20.x
```

**⚠️ IMPORTANT** :
- Root Directory = `frontend` (PAS vide)
- Output Directory = `dist` (relatif au Root Directory)
- Build Command = `npm run build` (PAS `cd frontend && ...`)

**EXPLICATION** :
Quand Root Directory = `frontend`, Vercel se place dans ce dossier.
Donc Output Directory = `dist` signifie `frontend/dist` pour Vercel.
