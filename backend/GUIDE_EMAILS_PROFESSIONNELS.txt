## 🔧 CONFIGURATION SUR RENDER

### **ÉTAPE 1 : Choisir l'email d'envoi**

Recommandation : `noreply@mima-elghalia.com`

**Pourquoi "noreply" ?**
- ✅ Indique clairement que c'est un email automatique
- ✅ Les utilisateurs ne tenteront pas de répondre
- ✅ Convention standard pour les emails transactionnels

### **ÉTAPE 2 : Configurer sur Render** (2 min)

1. **Aller sur** : https://dashboard.render.com
2. **Sélectionner** : `creche-backend`
3. **Onglet** : Environment
4. **Modifier** `EMAIL_FROM` :
   ```
   EMAIL_FROM = noreply@mima-elghalia.com
   ```
   
   **OU avec un nom d'affichage** :
   ```
   EMAIL_FROM = "Crèche Mima Elghalia <noreply@mima-elghalia.com>"
   ```

5. **Save Changes**

## 🎨 PERSONNALISER LES EMAILS PAR TYPE

Si vous voulez utiliser différents emails selon le type :

### **Dans le code backend** :

Modifier `backend/services/emailServiceResend.js` :

```javascript
// Email de confirmation d'inscription
sendEnrollmentConfirmation: async (enrollmentData) => {
  const emailContent = {
    from: 'inscription@mima-elghalia.com',  // ← Email spécifique
    to: applicant_email,
    subject: 'Confirmation de votre demande d\'inscription',
    // ...
  };
}

// Email d'approbation
sendEnrollmentApproval: async (enrollmentData) => {
  const emailContent = {
    from: 'contact@mima-elghalia.com',  // ← Email spécifique
    to: applicant_email,
    subject: 'Demande approuvée',
    // ...
  };
}

// Email de rejet
sendEnrollmentRejection: async (enrollmentData) => {
  const emailContent = {
    from: 'noreply@mima-elghalia.com',  // ← Email spécifique
    to: applicant_email,
    subject: 'Mise à jour de votre demande',
    // ...
  };
}
```

## 📧 RECEVOIR DES EMAILS (Optionnel)

Si vous voulez **RECEVOIR** des emails sur `contact@mima-elghalia.com` :

### **Option 1 : Redirection Gmail** (Gratuit)

1. Aller chez votre hébergeur DNS
2. Ajouter un enregistrement MX :
   ```
   Type: MX
   Nom: @
   Valeur: ASPMX.L.GOOGLE.COM
   Priorité: 1
   ```
3. Configurer Gmail pour recevoir les emails du domaine

### **Option 2 : Service email professionnel**

- **Google Workspace** : 6€/mois/utilisateur
- **Microsoft 365** : 5€/mois/utilisateur
- **Zoho Mail** : Gratuit (1 utilisateur)
