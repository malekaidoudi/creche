# 🚨 ACTIONS IMMÉDIATES SUR RENDER - EMAIL

---

## 📧 ÉTAPE 1 : MODIFIER LES VARIABLES RENDER (3 min)

### **Aller sur Render**
1. https://dashboard.render.com
2. Sélectionner `creche-backend`
3. Onglet **"Environment"**

### **Modifier SMTP_PORT**
- **Trouver** : `SMTP_PORT`
- **Valeur actuelle** : `587` ❌
- **Nouvelle valeur** : `465` ✅
- Cliquer **"Save Changes"**

### **Vérifier SMTP_PASSWORD**
- **Trouver** : `SMTP_PASSWORD`
- **Vérifier** : Pas d'espaces, 16 caractères
- Si doute, générer un nouveau (voir Étape 2)

---

## 🔑 ÉTAPE 2 : GÉNÉRER NOUVEAU MOT DE PASSE GMAIL (5 min)

### **Si l'email ne fonctionne toujours pas après Étape 1**

1. **Aller sur** : https://myaccount.google.com/apppasswords
2. **Se connecter** : crechemimaelghalia@gmail.com
3. **Créer un mot de passe d'application** :
   - Nom : "Render Backend Creche"
   - Cliquer "Créer"
4. **Copier le mot de passe** (16 caractères)
   - Format : `abcd efgh ijkl mnop`
   - **SUPPRIMER LES ESPACES** : `abcdefghijklmnop`
5. **Coller dans Render** :
   - Environment → `SMTP_PASSWORD`
   - Coller : `abcdefghijklmnop`
   - Save Changes

## 🧪 ÉTAPE 5 : TESTER L'ENVOI D'EMAIL

### **Test via API**
```bash
curl -X POST https://creche-backend.onrender.com/api/test-email \
  -H 'Content-Type: application/json' \
  -d '{"to":"votre@email.com"}'
```

### **Résultat attendu**
```json
{
  "success": true,
  "message": "Email envoyé avec succès"
}
```

### **Si erreur**
```json
{
  "success": false,
  "error": "..."
}
```

## 🆘 SI ÇA NE FONCTIONNE TOUJOURS PAS

### **Vérifications Gmail**

1. **Compte Gmail** :
   - Aller sur https://myaccount.google.com/security
   - Vérifier : Authentification à 2 facteurs ACTIVÉE
   - Vérifier : Aucune alerte de sécurité

2. **Mots de passe d'application** :
   - Aller sur https://myaccount.google.com/apppasswords
   - Supprimer les anciens mots de passe
   - Créer un nouveau

3. **Accès moins sécurisé** :
   - Gmail a peut-être bloqué l'accès
   - Vérifier les emails de sécurité Gmail
