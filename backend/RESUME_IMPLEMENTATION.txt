🗄️ TABLES POSTGRESQL CRÉÉES
═══════════════════════════════════════════════════════════════════════════════

Table: email_logs (11 colonnes)
─────────────────────────────────────────────────────────────────────────────
Stocke l'historique de tous les e-mails envoyés:
- id, email_type, recipient_email, sender_email
- subject, status, resend_id, error_message
- metadata (JSON), created_at, updated_at

Requête utile:
SELECT * FROM email_logs ORDER BY created_at DESC LIMIT 10;


Table: contact_messages (10 colonnes)
─────────────────────────────────────────────────────────────────────────────
Stocke les messages du formulaire de contact:
- id, name, email, phone, subject, message
- status, responded_at, responded_by, created_at

Requête utile:
SELECT * FROM contact_messages WHERE status = 'new' ORDER BY created_at DESC;

  email_type, 
  COUNT(*) as total,
  SUM(CASE WHEN status = 'sent' THEN 1 ELSE 0 END) as sent

⚠️ PROBLÈMES COURANTS ET SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

Problème: E-mails non reçus
─────────────────────────────────────────────────────────────────────────────
Solutions:
1. Vérifier les spams
2. Vérifier RESEND_API_KEY dans .env
3. Consulter les logs: SELECT * FROM email_logs WHERE status = 'failed'
4. Vérifier le dashboard Resend


Problème: Erreur "Domain not verified"
─────────────────────────────────────────────────────────────────────────────
Solutions:
1. Aller sur https://resend.com/domains
2. Ajouter le domaine mima-elghalia.com
3. Configurer les DNS (SPF, DKIM)
4. Attendre la vérification (quelques heures)

En attendant: Utiliser onboarding@resend.dev pour les tests


Problème: Variables non remplacées dans les templates
─────────────────────────────────────────────────────────────────────────────
Solutions:
1. Vérifier que les noms de variables correspondent exactement
2. Exemple: {{applicant_first_name}} dans le template
   doit correspondre à applicant_first_name: 'Ahmed' dans le code
