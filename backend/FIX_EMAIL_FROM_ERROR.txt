═══════════════════════════════════════════════════════════════════════════════

🔍 CAUSE DU PROBLÈME
═══════════════════════════════════════════════════════════════════════════════

Sur Render, quand vous configurez une variable d'environnement avec des 
guillemets, ils sont INCLUS dans la valeur de la variable.

❌ CONFIGURATION INCORRECTE:
EMAIL_FROM="Crèche Mima Elghalia <noreply@mima-elghalia.com>"

Valeur reçue par Node.js:
→ "Crèche Mima Elghalia <noreply@mima-elghalia.com>"
   ↑                                                  ↑
   Les guillemets sont DANS la valeur !

Resend reçoit donc:
from: '"Crèche Mima Elghalia <noreply@mima-elghalia.com>"'
      ↑ Format invalide à cause des guillemets                ↑

═══════════════════════════════════════════════════════════════════════════════

✅ SOLUTION 1: SUPPRIMER LES GUILLEMETS SUR RENDER (RECOMMANDÉ)
═══════════════════════════════════════════════════════════════════════════════

1. Aller sur https://dashboard.render.com
2. Sélectionner votre service backend
3. Aller dans l'onglet "Environment"
4. Trouver la variable EMAIL_FROM
5. Cliquer sur "Edit"
6. Modifier la valeur:

   AVANT:
   "Crèche Mima Elghalia <noreply@mima-elghalia.com>"

   APRÈS:
   Crèche Mima Elghalia <noreply@mima-elghalia.com>

7. Cliquer sur "Save Changes"
8. Render redémarrera automatiquement le service

✅ Résultat:
Node.js reçoit: Crèche Mima Elghalia <noreply@mima-elghalia.com>
Resend accepte: ✅ Format valide !

═══════════════════════════════════════════════════════════════════════════════

✅ SOLUTION 2: UTILISER SEULEMENT L'E-MAIL
═══════════════════════════════════════════════════════════════════════════════

Si le problème persiste, simplifier la configuration:

Sur Render:
EMAIL_FROM=noreply@mima-elghalia.com

Le nom sera ajouté automatiquement dans le code:
from: `Crèche Mima Elghalia <${process.env.EMAIL_FROM}>`

═══════════════════════════════════════════════════════════════════════════════

✅ SOLUTION 3: MODIFIER LE CODE POUR GÉRER LES GUILLEMETS
═══════════════════════════════════════════════════════════════════════════════

Ajouter dans emailService.js:

// Nettoyer EMAIL_FROM des guillemets éventuels
const cleanEmailFrom = (email) => {
  if (!email) return 'noreply@mima-elghalia.com';
  return email.replace(/^["']|["']$/g, '').trim();
};

// Utiliser dans sendEmail():
const emailData = {
  from: cleanEmailFrom(process.env.EMAIL_FROM) || `Crèche Mima Elghalia <${config.from}>`,
  to: recipient,
  subject: variables.subject || config.subject,
  html: htmlContent
};
