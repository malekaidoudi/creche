# 🗂️ SOLUTION : STOCKAGE FICHIERS PERSISTANT

## ❌ PROBLÈME ACTUEL

**Erreur** : `{"error":"Route non trouvée","path":"/uploads/enrollments/..."}`

### **Cause** :
Render utilise un **système de fichiers éphémère** :
- ✅ Fichiers uploadés pendant l'exécution
- ❌ Fichiers **perdus à chaque redéploiement**
- ❌ Fichiers **non partagés** entre instances

**Résultat** : Les documents uploadés disparaissent !

---

## ✅ SOLUTION : CLOUDINARY (Gratuit)

**Cloudinary** est un service de stockage cloud pour images et documents.

### **Avantages** :
- ✅ **Gratuit** : 25 GB stockage + 25 GB bande passante/mois
- ✅ **Persistant** : Fichiers jamais perdus
- ✅ **CDN** : Téléchargement rapide partout
- ✅ **API simple** : Upload en 3 lignes de code
- ✅ **Formats supportés** : Images (JPG, PNG) + PDF + Documents

   CLOUDINARY_API_SECRET = abcdefghijklmnopqrstuvwxyz

5. **Save Changes**

## 🆘 SI PROBLÈME

### **Erreur : "Cloudinary credentials not found"**

**Cause** : Variables d'environnement non configurées

**Solution** :
1. Vérifier sur Render → Environment
2. Variables présentes : `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`
3. Redémarrer si nécessaire

### **Erreur : "Upload failed"**

**Cause** : API Key ou Secret incorrect

**Solution** :
1. Vérifier les credentials sur Cloudinary Dashboard
2. Copier exactement (pas d'espaces)
3. Mettre à jour sur Render

### **Documents toujours en 404**

**Cause** : Anciens documents uploadés avant Cloudinary

**Solution** :
1. Les anciens documents sont perdus (stockage local)
2. Créer de nouvelles inscriptions
3. Les nouveaux documents seront sur Cloudinary
