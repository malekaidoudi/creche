**Erreur**: GET /api/enrollments/29 → 500 Internal Server Error
**Message**: "Erreur lors de la récupération du dossier"

**CAUSES POSSIBLES:**
- Table `enrollment_documents` n'existe pas
- Erreur de syntaxe SQL PostgreSQL
- Problème de connexion à la base de données

**DIAGNOSTIC À FAIRE:**
1. Vérifier les logs Render:

   ```sql
   SELECT table_name 
   FROM information_schema.tables
   ```

   ```bash
   curl https://creche-backend.onrender.com/api/enrollments/29 \
   ```
