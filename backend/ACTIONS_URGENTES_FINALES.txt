### **Exécuter dans Neon SQL Editor**

```sql

  ADD COLUMN IF NOT EXISTS rejected_by INTEGER REFERENCES users(id),
  ADD COLUMN IF NOT EXISTS rejected_at TIMESTAMP,
  ADD COLUMN IF NOT EXISTS rejection_type VARCHAR(50),
  ADD COLUMN IF NOT EXISTS rejection_reason TEXT;

-- Vérifier
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = 'enrollments' 
  AND column_name IN ('rejected_by', 'rejected_at', 'rejection_type', 'rejection_reason')
ORDER BY column_name;
```

## 📊 DIAGNOSTIC EMAIL - CAUSES POSSIBLES

### **Cause 1 : Mot de passe incorrect**
**Symptôme** : `❌ Erreur configuration email: Invalid login`
**Solution** : Générer un nouveau mot de passe d'application Gmail

### **Cause 2 : Authentification 2FA désactivée**
**Symptôme** : `❌ Erreur configuration email: Username and Password not accepted`
**Solution** : Activer 2FA sur le compte Gmail

### **Cause 3 : Variables d'environnement manquantes**
**Symptôme** : `passwordLength: 0` dans les logs
**Solution** : Vérifier que `SMTP_PASSWORD` est bien configuré sur Render

### **Cause 4 : Port ou host incorrect**
**Symptôme** : `❌ Erreur configuration email: Connection timeout`
**Solution** : Vérifier `SMTP_HOST=smtp.gmail.com` et `SMTP_PORT=587`

### **Cause 5 : Gmail bloque l'accès**
**Symptôme** : Email envoyé mais non reçu
**Solution** : 
1. Vérifier les spams
2. Vérifier https://myaccount.google.com/security
3. Autoriser "Applications moins sécurisées" (si nécessaire)
