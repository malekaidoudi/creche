## 🔧 ACTION 1 : AJOUTER LES COLONNES DE REJET

### **Problème**
```
Error: column "rejected_by" of relation "enrollments" does not exist
```

### **Solution : Exécuter le script SQL**

1. **Aller sur Neon** : https://console.neon.tech
2. **Sélectionner** : `mima_elghalia_db`
3. **Onglet** : SQL Editor
4. **Copier-coller ce script** :

```sql
-- Ajouter les colonnes de rejet manquantes
ALTER TABLE enrollments
  ADD COLUMN IF NOT EXISTS rejected_by INTEGER REFERENCES users(id),
  ADD COLUMN IF NOT EXISTS rejected_at TIMESTAMP,
  ADD COLUMN IF NOT EXISTS rejection_type VARCHAR(50),
  ADD COLUMN IF NOT EXISTS rejection_reason TEXT;

-- Vérifier que les colonnes ont été ajoutées
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = 'enrollments' 
  AND column_name IN ('rejected_by', 'rejected_at', 'rejection_type', 'rejection_reason')
ORDER BY column_name;
```

5. **Cliquer** : Run
6. **Résultat attendu** :
```
column_name        | data_type
-------------------|-----------
rejected_by        | integer
rejected_at        | timestamp
rejection_reason   | text
rejection_type     | character varying
```

## 📧 ACTION 2 : CORRIGER LE MOT DE PASSE EMAIL

### **Problème**
Emails non envoyés malgré configuration SMTP

### **Cause probable**
Mot de passe avec espaces : `qeyp kwpf yhhe voax`

### **Solution : Corriger sur Render**

1. **Aller sur** : https://dashboard.render.com
2. **Sélectionner** : `creche-backend`
3. **Onglet** : Environment
4. **Trouver** : `SMTP_PASSWORD`
5. **Modifier** :
   - ❌ **Avant** : `qeyp kwpf yhhe voax`
   - ✅ **Après** : `qeypkwpfyhhevoax`
6. **Cliquer** : Save Changes
7. **Attendre** : Render redémarre (1-2 min)

### **Vérifier après correction**
1. Render → Logs
2. Chercher au démarrage :
   ```
   ✅ Configuration email OK - Prêt à envoyer des emails
   ```
3. Créer une inscription de test
4. Chercher dans les logs :
   ```
   ✅ Email envoyé: <message-id>
   ```
