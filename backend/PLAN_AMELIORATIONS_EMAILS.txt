SOLUTION 3: LIEN CRÉATION MOT DE PASSE
═══════════════════════════════════════════════════════════════════════════════

A) Route backend pour valider le token:

   Nouvelle route:
   POST /api/auth/create-password
   
   Body:
   ```json
   {
     "token": "abc123...",
     "email": "parent@example.com",
     "password": "nouveauMotDePasse"
   }
   ```
   
   Logique:
   1. Vérifier que le token existe et n'est pas expiré
   2. Vérifier que l'e-mail correspond
   3. Hasher le mot de passe
   4. Créer le compte utilisateur (table users)
   5. Lier au dossier d'inscription
   6. Invalider le token
   7. Retourner JWT pour connexion automatique

B) Page frontend /create-password:
   
   ```jsx
   const CreatePassword = () => {
     const [token, setToken] = useState('');
     const [email, setEmail] = useState('');
     const [password, setPassword] = useState('');
     const [confirmPassword, setConfirmPassword] = useState('');
     
     useEffect(() => {
       const params = new URLSearchParams(window.location.search);
       setToken(params.get('token'));
       setEmail(params.get('email'));
     }, []);
     
     const handleSubmit = async (e) => {
       e.preventDefault();
       
       if (password !== confirmPassword) {
         alert('Les mots de passe ne correspondent pas');
         return;
       }
       
       const response = await fetch('/api/auth/create-password', {
         method: 'POST',
         headers: { 'Content-Type': 'application/json' },
         body: JSON.stringify({ token, email, password })
       });
       
       if (response.ok) {
         const data = await response.json();
         localStorage.setItem('token', data.token);
         window.location.href = '/dashboard';
       }
     };
     
     return (
       <form onSubmit={handleSubmit}>
         <h2>Créer votre mot de passe</h2>
         <input 
           type="password" 
           value={password}
           onChange={(e) => setPassword(e.target.value)}
           placeholder="Mot de passe"
           required
         />
         <input 
           type="password" 
           value={confirmPassword}
           onChange={(e) => setConfirmPassword(e.target.value)}
           placeholder="Confirmer le mot de passe"
           required
         />
         <button type="submit">Créer mon compte</button>
       </form>
     );
   };
   ```

C) Route backend complète:
   
   Fichier: routes_postgres/auth.js
   
   ```javascript
   router.post('/create-password', async (req, res) => {
     try {
       const { token, email, password } = req.body;
       
       // Validation
       if (!token || !email || !password) {
         return res.status(400).json({
           success: false,
           error: 'Données manquantes'
         });
       }
       
       // Vérifier le token
       const enrollment = await db.query(`
         SELECT * FROM enrollments
         WHERE applicant_email = $1
           AND password_token = $2
           AND password_token_expires > NOW()
           AND new_status = 'approved'
       `, [email, token]);
       
       if (enrollment.rows.length === 0) {
         return res.status(400).json({
           success: false,
           error: 'Token invalide ou expiré'
         });
       }
       
       const enrollmentData = enrollment.rows[0];
       
       // Hasher le mot de passe
       const hashedPassword = await bcrypt.hash(password, 10);
       
       // Créer le compte utilisateur
       const user = await db.query(`
         INSERT INTO users (
           first_name, last_name, email, password, role, created_at
         ) VALUES ($1, $2, $3, $4, 'parent', NOW())
         RETURNING id, first_name, last_name, email, role
       `, [
         enrollmentData.applicant_first_name,
         enrollmentData.applicant_last_name,
         email,
         hashedPassword
       ]);
       
       const userData = user.rows[0];
       
       // Invalider le token
       await db.query(`
         UPDATE enrollments
         SET password_token = NULL,
             password_token_expires = NULL,
             parent_user_id = $1
         WHERE id = $2
       `, [userData.id, enrollmentData.id]);
       
       // Générer JWT
       const jwtToken = jwt.sign(
         { id: userData.id, email: userData.email, role: userData.role },
         process.env.JWT_SECRET,
         { expiresIn: '7d' }
       );
       
       res.json({
         success: true,
         message: 'Compte créé avec succès',
         token: jwtToken,
         user: userData
       });
       
     } catch (error) {
       console.error('Erreur création mot de passe:', error);
       res.status(500).json({
         success: false,
         error: 'Erreur lors de la création du compte'
       });
     }
   });
   ```
