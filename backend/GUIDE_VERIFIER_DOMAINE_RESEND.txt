## 🚀 ÉTAPE 1 : AJOUTER LE DOMAINE (2 min)

1. **Aller sur** : https://resend.com/domains
2. **Cliquer** : "Add Domain"
3. **Entrer votre domaine** :
   - Si vous avez : `crechemimaelghalia.tn`
   - Ou : `creche-mimaelghalia.com`
   - Ou tout autre domaine que vous possédez
4. **Cliquer** : "Add"

---

## 📋 ÉTAPE 2 : COPIER LES ENREGISTREMENTS DNS (1 min)

Resend va vous donner **3 enregistrements DNS** à ajouter :

### **1. Enregistrement SPF (TXT)**
```
Type: TXT
Nom: @
Valeur: v=spf1 include:_spf.resend.com ~all
```

### **2. Enregistrement DKIM (TXT)**
```
Type: TXT
Nom: resend._domainkey
Valeur: (une longue chaîne fournie par Resend)
```

### **3. Enregistrement DMARC (TXT)**
```
Type: TXT
Nom: _dmarc
Valeur: v=DMARC1; p=none
```

**⚠️ IMPORTANT** : Copier exactement les valeurs fournies par Resend.

---

## 🌐 ÉTAPE 3 : AJOUTER LES ENREGISTREMENTS CHEZ VOTRE HÉBERGEUR (5 min)

### **Si votre domaine est chez GoDaddy** :

1. **Aller sur** : https://dcc.godaddy.com/manage/dns
2. **Sélectionner** votre domaine
3. **Cliquer** : "DNS" → "Manage"
4. **Ajouter** les 3 enregistrements TXT
5. **Sauvegarder**

### **Si votre domaine est chez Namecheap** :

1. **Aller sur** : https://ap.www.namecheap.com/domains/list
2. **Cliquer** : "Manage" à côté de votre domaine
3. **Onglet** : "Advanced DNS"
4. **Ajouter** les 3 enregistrements TXT
5. **Sauvegarder**

### **Si votre domaine est chez OVH** :

1. **Aller sur** : https://www.ovh.com/manager/web/
2. **Sélectionner** votre domaine
3. **Onglet** : "Zone DNS"
4. **Ajouter** les 3 enregistrements TXT
5. **Sauvegarder**

### **Si votre domaine est chez Cloudflare** :

1. **Aller sur** : https://dash.cloudflare.com
2. **Sélectionner** votre domaine
3. **Onglet** : "DNS"
4. **Ajouter** les 3 enregistrements TXT
5. **Sauvegarder**

---

## ⏳ ÉTAPE 4 : ATTENDRE LA PROPAGATION (5-15 min)

Les enregistrements DNS prennent **5 à 15 minutes** pour se propager.

**Vérifier la propagation** :
1. Aller sur : https://mxtoolbox.com/SuperTool.aspx
2. Entrer : `votredomaine.tn`
3. Sélectionner : "TXT Lookup"
4. Vérifier que les enregistrements apparaissent

---

## ✅ ÉTAPE 5 : VÉRIFIER SUR RESEND (1 min)

1. **Retourner sur** : https://resend.com/domains
2. **Cliquer** : "Verify" à côté de votre domaine
3. **Résultat attendu** : ✅ "Domain verified"

**Si erreur** : Attendre encore 5-10 minutes et réessayer.
