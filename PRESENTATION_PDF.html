1. Présentation Générale

🎯 Objectif du Projet

Mima El Ghalia est une application web moderne de gestion de crèche qui digitalise l'ensemble des processus administratifs et opérationnels.

✅ Inscriptions en ligne

Formulaire complet avec upload de documents

📊 Suivi de présence

Pointage quotidien et rapports

💬 Communication

Messagerie parents-staff intégrée

📁 Gestion documentaire

Stockage sécurisé des fichiers

2. Fonctionnalités Principales

📝 Module Inscription

Inscription Publique (sans compte)

  • Formulaire d'inscription en ligne complet
  • Upload de documents (carnet de santé, photos, etc.)
  • Sélection de créneaux de rendez-vous
  • Validation du règlement intérieur obligatoire
  • Confirmation par email automatique

Gestion Admin des Inscriptions

  • Liste des demandes en attente
  • Validation/Rejet avec motif
  • Planification de rendez-vous
  • Création automatique du compte parent

👶 Module Enfants

Fiche Complète

Informations personnelles, contacts d'urgence, informations médicales, photo de profil

Documents

Upload multi-fichiers, catégorisation, visualisation et téléchargement

📊 Module Présence

Enregistrement

Pointage arrivée/départ, vue calendrier mensuel

Rapports

Statistiques par enfant, taux de présence, graphiques

📅 Module Jours Fériés

  • Jours fériés nationaux tunisiens (automatique)
  • Jours fériés religieux islamiques
  • Vacances scolaires
  • Toggle ON/OFF pour chaque jour
  • Impact automatique sur le calcul de présence

5. Sécurité

🔐 Authentification JWT

  • Token signé avec secret fort
  • Expiration 24h
  • Refresh token

🔒 Mots de Passe

  • Hashage bcrypt (12 rounds)
  • Validation complexité
  • Reset par email

🛡️ Protection Données

  • Validation entrées
  • Protection SQL injection
  • Protection XSS

🔑 Contrôle d'Accès

  • RBAC (rôles)
  • Routes protégées
  • HTTPS obligatoire
