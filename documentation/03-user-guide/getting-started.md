# Premiers pas : connexion, mot de passe, navigation

## Se connecter
- **Objectif** : accéder à son espace.
- **Qui** : tous les utilisateurs ayant un compte (parent, personnel, administrateur).
- **Prérequis** : un compte actif avec mot de passe défini.
- **Comment** : page de connexion → e-mail + mot de passe → vous êtes redirigé vers « Mon Espace » (parent) ou le tableau de bord (personnel/administration).
- **Résultat** : session ouverte (valable 7 jours par défaut ; pas de déconnexion automatique côté serveur).
- **Erreurs possibles** : identifiants incorrects ; compte désactivé.
- **Limites** : la déconnexion supprime seulement la session du navigateur.

## Créer son mot de passe (première connexion)
1. Ouvrir le lien reçu par e-mail (valable **7 jours**).
2. Saisir un mot de passe (6 caractères minimum).
3. Vous êtes connecté automatiquement.
Lien expiré → demander à la direction de le renvoyer.

## Mot de passe oublié
1. « Mot de passe oublié » → saisir l'e-mail.
2. Un lien (valable **1 heure**) est envoyé si le compte existe (message identique dans tous les cas).
3. Choisir un nouveau mot de passe.

## Changer de langue / thème
Français ou arabe (affichage de droite à gauche), thème clair ou sombre.

## Navigation
- Parent : menu « Mon Espace ».
- Personnel/admin : barre latérale filtrée selon le rôle. Voir la [carte des écrans](../06-technical/ui-screens.md).
