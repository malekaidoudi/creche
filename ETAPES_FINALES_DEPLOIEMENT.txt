ÉTAPE 2: Exécuter la Migration SQL sur Neon
────────────────────────────────────────────────────────────────────────────
Status: ⏳ EN ATTENTE

Une fois le backend redéployé, créer la table tasks:

Option A - Via Interface Neon (RECOMMANDÉ):
1. Se connecter à https://console.neon.tech
2. Sélectionner le projet/base de données
3. Ouvrir "SQL Editor"
4. Copier le contenu de: backend/database/migrations/create_tasks.sql
5. Exécuter le script
6. Vérifier: SELECT COUNT(*) FROM tasks;

Option B - Via CLI:
```bash
psql $DATABASE_URL -f backend/database/migrations/create_tasks.sql
```

Vérification:
```sql
-- Vérifier que la table existe
\dt tasks

-- Vérifier les colonnes
\d tasks

-- Vérifier les index
\di tasks*
```
