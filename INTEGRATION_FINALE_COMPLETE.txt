   Modifications:
   ✅ Import du composant ApproveEnrollmentModal
   ✅ Ajout du state showApproveModal
   ✅ Création de handleApproveClick(enrollment)
   ✅ Refactorisation de handleApprove(enrollmentId, appointmentDate)
   ✅ Changement du bouton "Approuver" pour utiliser handleApproveClick
   ✅ Ajout du modal à la fin du JSX

   Avant:
   ```jsx
   const handleApprove = async (enrollment) => {
     await enrollmentsService.approveEnrollment(enrollment.id, {
       appointment_date: new Date().toISOString().split('T')[0],
       admin_comment: `Approuvé par ${user?.first_name}`
     });
   };

   <Button onClick={() => handleApprove(enrollment)}>
     Approuver
   </Button>
   ```

   Après:
   ```jsx
   const [showApproveModal, setShowApproveModal] = useState(false);

   const handleApproveClick = (enrollment) => {
     setSelectedEnrollment(enrollment);
     setShowApproveModal(true);
   };

   const handleApprove = async (enrollmentId, appointmentDate) => {
     await enrollmentsService.approveEnrollment(enrollmentId, {
       appointment_date: appointmentDate
     });
     setShowApproveModal(false);
     await fetchPendingEnrollments();
   };

   <Button onClick={() => handleApproveClick(enrollment)}>
     Approuver
   </Button>

   <ApproveEnrollmentModal
     isOpen={showApproveModal}
     onClose={() => setShowApproveModal(false)}
     enrollment={selectedEnrollment}
     onApprove={handleApprove}
   />
   ```

🎯 FLOW COMPLET D'APPROBATION
═══════════════════════════════════════════════════════════════════════════════

1. Staff/Admin clique sur "Approuver" dans la liste des inscriptions
   ↓
2. Modal s'ouvre avec infos enfant/parent
   ↓
3. Staff/Admin sélectionne date et heure du rendez-vous
   ↓
4. Validation: date >= aujourd'hui
   ↓
5. Clic sur "Approuver"
   ↓
6. API POST /api/enrollments/:id/approve
   Body: { appointment_date: "2025-01-08T10:00:00" }
   ↓
7. Backend:
   - Met à jour le statut → "approved"
   - Génère token création MDP (48h)
   - Formate la date en français
   - Envoie e-mail avec:
     * Date RDV formatée: "lundi 8 janvier 2025 à 10:00"
     * Lien création MDP: /create-password?token=xxx&email=yyy
     * Liste documents à apporter
   ↓
8. Frontend:
   - Toast de succès
   - Modal se ferme
   - Liste se rafraîchit
   - Dossier disparaît de "En attente"
   ↓
9. Parent reçoit e-mail
   ↓
10. Parent clique sur lien création MDP
   ↓
11. Page CreatePassword s'ouvre
   ↓
12. Parent crée son mot de passe
   ↓
13. Compte créé + connexion automatique
   ↓
14. Redirection vers dashboard parent
